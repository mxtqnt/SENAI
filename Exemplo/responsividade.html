Guia Rápido de Responsividade

Responsividade é fazer o site se adaptar a qualquer tamanho de tela — celular, tablet ou computador. Cada bloco abaixo mostra UMA técnica usada no projeto.

Nos exemplos com moldura tracejada, arraste o cantinho inferior direito para redimensionar e veja o layout mudar sozinho.

1. A tag viewport (obrigatória)

Sem essa linha no <head>, o celular finge ser uma tela larga e mostra o site minúsculo. Ela diz ao navegador: "use a largura real do aparelho e não dê zoom automático".

<meta name="viewport" content="width=device-width, initial-scale=1.0">
Essa tag não tem efeito visual para mostrar aqui — mas é a primeira coisa que todo site responsivo precisa ter.

2. Container fluido

max-width impede que o conteúdo fique largo demais em telas grandes, e width: 100% permite encolher em telas pequenas.

.container {
    max-width: 500px;
    width: 100%;
    margin: 0 auto;
    padding: 0 16px;
}

Encolha a janela do navegador — eu nunca ultrapasso 500px, mas encolho sem problemas.

3. Imagem fluida

Sem isso, uma imagem grande pode "estourar" a tela em celulares. Com max-width: 100%, ela nunca ultrapassa o tamanho do elemento pai.

img {
    max-width: 100%;
    height: auto;
}

4. Flexbox com quebra de linha

flex-wrap: wrap permite que os itens passem para a linha de baixo quando não cabem mais lado a lado. Redimensione a janela do navegador para ver.

.linha {
    display: flex;
    flex-wrap: wrap;
    gap: 10px;
}
.linha > div {
    flex: 1 1 160px; /* cresce, encolhe, e prefere 160px */
}

5. Grade automática (Grid + auto-fit)

O número de colunas se ajusta sozinho, sem precisar de media query. minmax(140px, 1fr) diz: "cada coluna tem no mínimo 140px, e some quantas couberem".

.grade {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(140px, 1fr));
    gap: 10px;
}

6. Media Query: menu que empilha no celular

A media query aplica um CSS diferente só quando a tela é estreita. Aqui, o menu vira coluna e centraliza abaixo de 768px de largura.

@media (max-width: 768px) {
    header .container {
        flex-direction: column;
        text-align: center;
    }
    header nav ul {
        flex-direction: column;
    }
}

↳ Arraste o canto inferior direito da moldura para menos de ~400px de largura e veja o menu virar coluna.

7. Media Query: colunas que empilham

A mesma ideia da técnica 6, aplicada a uma seção de duas colunas: em telas largas ficam lado a lado, em telas estreitas uma fica embaixo da outra.

.split {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}
.split > * {
    flex: 1 1 200px; /* já empilha sozinho quando não cabe mais */
}

↳ Arraste a moldura para menos de ~350px de largura e veja as colunas empilharem — aqui isso acontece sozinho com flex-wrap, sem nem precisar de media query.
