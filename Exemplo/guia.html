Guia Rápido de Técnicas CSS

Cada bloco abaixo mostra o código e o resultado de UMA técnica usada no site da campanha. Use "Inspecionar elemento" do navegador para ver o código rodando ao vivo.

1. Navegação por âncora

O link usa href="#nome" e o elemento de destino tem id="nome". O navegador rola a página até ele.

<a href="#alvo">Ir para o alvo</a>

...

<div id="alvo">Cheguei!</div>

html { scroll-behavior: smooth; }
Clique aqui para descer até o alvo
Você chegou ao alvo! 🎯

2. Gradiente de cor

linear-gradient() mistura duas cores em uma direção escolhida.

.caixa {
    background: linear-gradient(135deg, #c62828, #e57373);
}

3. Efeito escuro sobre uma imagem

Sobrepomos um gradiente escuro por cima da imagem de fundo, usando duas camadas separadas por vírgula.

.caixa {
    background:
        linear-gradient(rgba(0,0,0,0.55), rgba(0,0,0,0.55)),
        url('img/foto.jpg') center/cover no-repeat;
}
Texto legível sobre a foto

4. Centralizar com Flexbox

display: flex + align-items + justify-content centralizam o conteúdo nos dois eixos.

.caixa {
    display: flex;
    align-items: center;
    justify-content: center;
}
Estou centralizado!

5. Grade de cartões com Grid

grid-template-columns: repeat(auto-fit, minmax(...)) cria colunas que se reorganizam sozinhas.

.grade {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(140px, 1fr));
    gap: 12px;
}

6. Cantos arredondados e sombra

border-radius arredonda; box-shadow adiciona profundidade.

.caixa {
    border-radius: 12px;
    box-shadow: 0 8px 20px rgba(0,0,0,0.2);
}

7. Sanfona (accordion) sem JavaScript

As tags <details> e <summary> já funcionam sozinhas, sem precisar de nenhum script.

<details>
    <summary>Clique para abrir</summary>
    <p>Conteúdo escondido aqui.</p>
</details>

8. Botão com efeito ao passar o mouse

:hover muda o estilo quando o mouse passa por cima; transition suaviza a mudança.

.botao {
    transition: background-color 0.3s ease, transform 0.3s ease;
}
.botao:hover {
    background-color: #e57373;
    transform: translateY(-3px);
}
