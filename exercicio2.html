Exercício 2 — Menu com Links de Âncora

Crie um cabeçalho com um menu de navegação. Cada link deve levar até uma seção diferente da mesma página, usando href="#id" e um elemento com o id correspondente.

Wireframe

[ LOGO ]
[ Link 1 ] [ Link 2 ] [ Link 3 ]
[ Seção 1 ]
[ Seção 2 ]
[ Seção 3 ]

Tela Objetivo

Mostrar tela objetivo
SalvaVidas
  • Início
  • Sobre
  • Contato

Clicar em um link rola a página suavemente até a seção com o mesmo id (use scroll-behavior: smooth no CSS).

Esqueleto HTML

<header>
    <div class="container">
        <a href="#">Logo</a>
        <nav>
            <ul>
                <li><a href="#secao1">Link 1</a></li>
                <li><a href="#secao2">Link 2</a></li>
                <li><a href="#secao3">Link 3</a></li>
            </ul>
        </nav>
    </div>
</header>

<main>
    <section id="secao1"></section>
    <section id="secao2"></section>
    <section id="secao3"></section>
</main>

Esqueleto CSS

html {
    scroll-behavior: smooth;
}

header {

}

header nav ul {
    list-style: none;
    display: flex;
}
