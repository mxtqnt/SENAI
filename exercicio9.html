Exercício 9 — Sanfona de Perguntas (sem JavaScript)

Construa uma lista de perguntas que abrem e fecham ao clicar, usando apenas as tags <details> e <summary> — sem nenhuma linha de JavaScript.

Wireframe

[ + Pergunta 1 ]
[ + Pergunta 2 ]
[ + Pergunta 3 ]

Tela Objetivo

Mostrar tela objetivo
Dói para doar sangue?

Não. O desconforto é leve e o processo é rápido.

Quanto tempo leva?

De 10 a 15 minutos.

Esqueleto HTML

<details>
    <summary></summary>
    <p></p>
</details>

<details>
    <summary></summary>
    <p></p>
</details>

Esqueleto CSS

details {
    border: 1px solid #eee;
    border-radius: 6px;
    padding: 0 16px;
}

summary {
    cursor: pointer;
    padding: 12px 0;
    font-weight: bold;
}
