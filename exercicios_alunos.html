Exercícios em Portugol (Vetores Estáticos)

Exercício 1: Descobrindo o Índice

Descrição: Dado um vetor de 5 nomes já preenchido, escreva um algoritmo que receba um nome digitado pelo usuário e informe em qual posição (índice) esse nome se encontra.

Dicas: Use um laço para (for) para percorrer o vetor. Crie uma variável inteira posicao_encontrada iniciada com -1. Se o nome for igual ao elemento do vetor, guarde o índice nessa variável e use o comando pare (break).
programa {
  funcao inicio() {
    cadeia nomes[5] = {"Ana", "Bruno", "Carlos", "Daniela", "Eduardo"}
    cadeia busca
    inteiro posicao = -1
    
    escreva("Digite um nome para buscar: ")
    leia(busca)
    
    para(inteiro i=0; i < 5; i++){
      se(nomes[i] == busca){
        posicao = i
        pare
      }
    }
    escreva("Posicao: ", posicao)
  }
}

Exercício 2: Deslocamento Manual de Elementos

Descrição: Você possui um vetor numérico de 5 posições [10, 20, 30, 40, 50]. O elemento da posição 2 (o número 30) precisa ser apagado. Faça um laço de repetição que mova os elementos das posições 3 e 4 uma casa para trás, cobrindo o 30.

Dicas: O laço deve começar a partir do índice que será apagado (2) e ir até o penúltimo elemento. A lógica principal será vetor[i] = vetor[i+1].
programa {
  funcao inicio() {
    inteiro vetor[5] = {10, 20, 30, 40, 50}
    // Removendo o índice 2 (valor 30)
    para(inteiro i=2; i < 4; i++){
      vetor[i] = vetor[i+1]
    }
    // Impressão para teste
    para(inteiro i=0; i < 4; i++){
      escreva(vetor[i], " ")
    }
  }
}

Exercício 3: Tratamento de Elemento Inexistente

Descrição: Crie um algoritmo que busca um produto em um vetor. Se o produto existir, exiba "Produto encontrado". Se o laço terminar e o produto não estiver no vetor, o sistema deve exibir de forma elegante: "Erro: Produto não cadastrado".

Dicas: Use uma variável do tipo logico (booleana) chamada encontrou, inicializada como falso. Mude para verdadeiro apenas se achar o item. Faça o teste final (se encontrou == falso) fora do laço.
programa {
  funcao inicio() {
    cadeia produtos[3] = {"Mesa", "Cadeira", "Sofa"}
    cadeia busca = "Armario"
    logico encontrou = falso
    
    para(inteiro i=0; i < 3; i++){
      se(produtos[i] == busca){
        encontrou = verdadeiro
        escreva("Produto encontrado.")
        pare
      }
    }
    se(encontrou == falso){
      escreva("Erro: Produto nao cadastrado.")
    }
  }
}

Exercício 4: A Remoção Completa

Descrição: Una os exercícios 1 e 2. Crie um vetor de 5 clientes e uma variável total_clientes = 5. Peça um nome para remover. Encontre o índice desse nome. Se encontrar, faça o deslocamento dos elementos seguintes para trás e diminua a variável total_clientes em 1. Imprima a lista no final.

Dicas: Lembre-se de que, ao imprimir, o laço de listagem deve ir de 0 até total_clientes - 1. A última posição original do vetor não importará mais, pois o total_clientes ditará o limite.
programa {
  funcao inicio() {
    cadeia clientes[5] = {"João", "Maria", "José", "Ana", "Bia"}
    inteiro total = 5
    cadeia busca
    inteiro pos_remover = -1
    
    escreva("Quem deseja remover? ")
    leia(busca)
    
    para(inteiro i=0; i < total; i++){
      se(clientes[i] == busca){
        pos_remover = i
        pare
      }
    }
    
    se(pos_remover != -1){
      para(inteiro i=pos_remover; i < total - 1; i++){
        clientes[i] = clientes[i+1]
      }
      total = total - 1
      escreva("Removido com sucesso.
")
    } senao {
      escreva("Nao encontrado.
")
    }
    
    // Lista atualizada
    para(inteiro i=0; i < total; i++){
      escreva(clientes[i], "
")
    }
  }
}

Exercício 5: Adicionando Opção em Menu

Descrição: Pegue uma estrutura de menu simples (enquanto opcao != 3) com opções 1 e 2. Adicione uma nova opção de número 3 para "Remover" e altere a condição de saída para o número 4.

Dicas: Tenha cuidado com a estrutura se / senao se. Garanta que a opção de saída só encerre o programa se for escolhido exatamente o número correto.
programa {
  funcao inicio() {
    inteiro opcao = 0
    enquanto(opcao != 4){
      escreva("
1 - Cadastro
2 - Lista
3 - Remover
4 - Sair
Opcao: ")
      leia(opcao)
      se(opcao == 1){ escreva("Cadastrando...") }
      senao se(opcao == 2){ escreva("Listando...") }
      senao se(opcao == 3){ escreva("Removendo...") }
      senao se(opcao == 4){ escreva("Saindo...") }
      senao { escreva("Invalido") }
    }
  }
}


Exercícios em Python (Listas Dinâmicas)

Exercício 1: Busca Manual de Índice em Lista

Descrição: Dada a lista frutas = ["Maca", "Banana", "Uva", "Pera"], solicite uma fruta ao usuário. Usando um laço for clássico com range(len(frutas)), encontre e imprima o índice numérico da fruta digitada.

Dicas: Embora Python tenha o método .index(), treine a lógica base usando for i in range(len(frutas)): para entender como a máquina varre a memória.
frutas = ["Maca", "Banana", "Uva", "Pera"]
busca = input("Digite a fruta: ")
posicao = -1

for i in range(len(frutas)):
    if frutas[i] == busca:
        posicao = i
        break

print(f"Posicao encontrada: {posicao}")

Descrição: Escreva um script que tenta remover a cor "Azul" de uma lista de cores. O programa não pode quebrar (apresentar ValueError) caso "Azul" não esteja na lista.

Dicas: Antes de usar o método cores.remove("Azul"), utilize o operador lógico in (ex: if "Azul" in cores:) para garantir que o elemento existe.
cores = ["Vermelho", "Verde", "Amarelo"]
busca = "Azul"

if busca in cores:

Exercício 3: Deslocamento Manual em Python

Descrição: Para entender o que o Python faz nos bastidores, crie uma lista [100, 200, 300, 400, 500]. Peça para remover o índice 1. Sem usar .remove(), .pop() ou del, faça um laço for que desloque os itens da direita para a esquerda, e no final remova o último item duplicado usando .pop() vazio.

Dicas: O laço deve ir do índice a ser removido até o penúltimo. lista[i] = lista[i+1]. O último comando será lista.pop().
lista = [100, 200, 300, 400, 500]
indice_remover = 1 # Remover o 200

# Desloca da direita para a esquerda
for i in range(indice_remover, len(lista) - 1):
    lista[i] = lista[i+1]
    
# Remove o item duplicado no final
lista.pop()
print(lista) # Saida: [100, 300, 400, 500]

Exercício 4: Função de Remoção com Retorno de Status

Descrição: Crie uma função chamada deletar_item(lista, nome). Se o nome for encontrado e removido, a função retorna True. Se não for encontrado, retorna False. Fora da função, imprima uma mensagem de sucesso ou falha com base no retorno.

Dicas: Funções em Python são ótimas para encapsular ações perigosas. Use um bloco try / except ValueError ou a verificação com in dentro da função.
def deletar_item(lista, nome):
    if nome in lista:
        lista.remove(nome)
        return True
    return False

usuarios = ["Tiago", "Julia", "Marcos"]
nome_remover = input("Quem deseja remover? ")

if deletar_item(usuarios, nome_remover):
    print("Sucesso: Usuario removido.")
else:
    print("Falha: Usuario inexistente.")

Exercício 5: Integração no Menu com Validação

Descrição: Crie um laço while True: simulando um sistema. Tenha a opção "1 - Remover". Quando o usuário digitar 1, peça o nome. Chame uma lógica de remoção. Caso o usuário digite letras em vez da opção numérica do menu, trate o erro sem fechar o sistema.

Dicas: Para ler a opção do menu, use um bloco try / except ValueError. Isso prepara o aluno para cenários reais onde o usuário digita texto no lugar de números.
usuarios = ["Aline", "Felipe"]
while True:
    print("\n1 - Remover Usuario\n2 - Sair")
    try:
        opcao = int(input("Escolha: "))
    except ValueError:
        print("Erro: Digite apenas numeros.")
        continue

    if opcao == 1:
        nome = input("Digite o nome: ")
        if nome in usuarios:
            usuarios.remove(nome)
            print("Removido.")
        else:
            print("Nao encontrado.")
    elif opcao == 2:
        print("Saindo...")
        break
    else:
        print("Opcao invalida.")
