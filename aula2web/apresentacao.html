Recuperação EaD

Etapas 1 e 2: Base do Projeto

Antes de codificar, precisamos da estrutura lógica:

  • Conteúdo: Escolha dos destinos e textos descritivos.
  • Wireframe: Esboço visual da estrutura (layout e grids).
  • Navegação: Máquina de estados para os hiperlinks (home > destinos > detalhes).
  • Estilo: Definição das fontes (usando WhatFont) e esquema de cores (Preto e Branco).
Laboratório

Etapa 3: Desenvolvimento

A transição do visual para o código estruturado.

  • Diretórios: Criação das pastas css/, img/ e do arquivo index.html.
  • Semântica: Uso estrito de <header>, <nav>, <section>, e <article>.
  • Layout Flex/Grid: Alinhamento com Flexbox no topo e CSS Grid para a disposição fluída dos pacotes de turismo.
Validação

Testes e Responsividade

Um site moderno precisa funcionar em qualquer tela.

  • Live Server: Validação em tempo real das alterações feitas no código.
  • Mobile First: O CSS padrão deve ser pensado para o celular, usando @media (min-width: 768px) para telas maiores.
  • Cross-browser: Abrir o IP local no Chrome, Firefox e Edge para validar a renderização.
  • Relatório Final: Arquivo txt ou pdf descrevendo as alterações.
