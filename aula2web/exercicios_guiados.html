Guia Prático: Projeto FlatTour

Siga os 10 passos abaixo para construir o layout final. Algumas etapas possuem dicas ocultas para auxiliar na lógica.

01 Setup Inicial: VS Code e Live Server

Abra a pasta do projeto no VS Code e crie o arquivo index.html estruturando o boilerplate básico do HTML5. Em seguida, clique em "Go Live" (no rodapé do VS Code) ou clique com o botão direito no arquivo e escolha "Open with Live Server" para ver suas atualizações em tempo real.

02 Tags Semânticas

Adicione o <header> para o topo, uma seção principal e o <footer> no final do body. Estruture a navegação com a tag <nav> e uma lista não ordenada.

03 Conteúdo Base e Cards

Crie as duas seções de destinos (Nacionais e Internacionais). Dentro de cada uma, adicione a tag <article> para representar os cards individuais de cada cidade.

Dica Semântica: Utilize <section id="nacionais"> para englobar as categorias e crie uma <div class="grid-container"> dentro dela para agrupar todos os <article class="card">. Isso facilitará muito a aplicação do CSS Grid depois!

04 Reset CSS e Variáveis

No arquivo style.css (lembre de importá-lo no HTML), remova as margens e paddings padrão. Crie as variáveis de cor (preto, branco, tons de cinza) no seletor :root.

05 Tipografia Minimalista

Configure a fonte do body para Helvetica Neue ou Arial. Transforme os títulos (h1, h2, h3) em maiúsculas e adicione espaçamento entre as letras (letter-spacing).

06 Header com Flexbox

Faça com que o logotipo e o menu de navegação fiquem alinhados nas extremidades da tela, lado a lado.

Dica de Flexbox: Aplique no .header as regras: display: flex;, justify-content: space-between; e align-items: center;. Faça o mesmo na lista (ul) da navegação usando gap para o espaçamento.

07 Estilizando a Hero Section

Destaque a seção de boas-vindas. Centralize o conteúdo, crie um botão flat (com bordas sólidas) e aplique uma sombra sólida usando box-shadow preta sem desfoque (blur 0px).

08 Construindo a Grade (Grid)

Posicione os cards de destinos lado a lado. Eles devem ocupar o máximo de espaço possível, se adaptando à tela de forma inteligente sem "quebrar" bruscamente.

Dica de CSS Grid: Para um layout perfeitamente flexível, aplique no seu container de cards: display: grid; e a mágica grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));.

09 Filtros e Efeitos P&B

Garanta que as imagens dos cartões percam toda a cor, respeitando o estilo flat preto e branco, utilizando a propriedade filter do CSS. Adicione também um efeito de transição ao passar o mouse.

10 Mobile First e Media Queries

Ajuste o layout para smartphones. Certifique-se de que o menu em linha se torne empilhado em telas pequenas (menores que 768px) e que as fontes dos títulos diminuam para evitar rolagem horizontal. Salve o arquivo e veja a página recarregar sozinha no Live Server!
