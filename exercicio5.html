Exercício 5 — Lista com Ícones Alinhados

Monte uma lista onde cada item tem um pequeno ícone (ou bolinha colorida) alinhado ao lado do texto, usando Flexbox dentro do <li>.

Wireframe

Tela Objetivo

Mostrar tela objetivo
  • 1 doação pode beneficiar até 4 pessoas
  • Cerca de 450 ml são coletados por doação
  • O processo dura de 10 a 15 minutos

Esqueleto HTML

<ul class="stat-list">
    <li><svg></svg> Texto do item 1</li>
    <li><svg></svg> Texto do item 2</li>
    <li><svg></svg> Texto do item 3</li>
</ul>

Esqueleto CSS

.stat-list {
    list-style: none;
}

.stat-list li {
    display: flex;
    align-items: center;
    gap: 10px;
}
