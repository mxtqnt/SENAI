Exercício 1 — Estrutura Semântica

Monte o esqueleto de uma página usando as tags semânticas <header>, <main>, <section> e <footer>. Não é preciso estilizar nada ainda — o objetivo é organizar o HTML nos blocos corretos.

Wireframe

[ HEADER ]
[ MAIN > SECTION ]
[ FOOTER ]

Tela Objetivo

Mostrar tela objetivo
header
main > section
footer

As cores aqui são só para você enxergar os limites de cada área — no HTML puro elas ficam invisíveis.

<body>

    </header>

    <main>

        <section>

        </section>

    </main>

    <footer>

    </footer>

</body>
