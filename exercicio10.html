Tela Objetivo

Mostrar tela objetivo

↳ Arraste o canto da moldura para menos de ~400px e veja o menu virar coluna.

Esqueleto HTML

<header>
    <div class="container">
        <a href="#" class="logo"></a>
        <nav>
            <ul>
                <li><a href="#"></a></li>
                <li><a href="#"></a></li>
            </ul>
        </nav>
    </div>
</header>

Esqueleto CSS

header .container {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

@media (max-width: 768px) {
    header .container {
        flex-direction: column;
        text-align: center;
    }
    header nav ul {
        flex-direction: column;
    }
}
